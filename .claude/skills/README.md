# Agent-Skills für alle Studio-Kanäle

| Skill | Quelle | Wofür |
|---|---|---|
| remotion-best-practices | offiziell von Remotion (github.com/remotion-dev/skills, v4.0.547) | Router für alle Remotion-Themen: Markup/Animation, Captions, Render, Maps, Multimedia. Alle Original-Kanäle rendern mit Remotion. Update: `npx remotion skills add` |
| ffmpeg | Digital Samba, claude-code-video-toolkit (MIT, LICENSE liegt bei) | Schneiden, Zuschneiden 9:16, Komprimieren, Audio, YouTube-/Shorts-Export-Settings – vor allem für die Clip-Kanäle (The Podcast Cut, RageLoop Clips) |
| shorts-retention | eigene Regeln aus unseren Analytics + vidIQ | Hook, Länge, Loop, CTA, Diagnose – vor jedem Short laden |

Geprüft, nicht installiert: agricidaniel/claude-video `video-shorts` (Langvideo → Clips, WhisperX + Gemini-Key + eigene Skripte; Kandidat, sobald die Clip-Kanäle starten) und everything-claude-code `video-editing` (allgemeiner Workflow mit Descript/CapCut, passt nicht zur Automatik).
